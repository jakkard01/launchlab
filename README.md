# Powered by IA

Commercial website for **Powered by IA**, focused on clear, mobile-first websites for local businesses.

## What this project demonstrates

- Mobile-first web design
- Clear presentation of services
- UX oriented toward contact and conversion
- Direct WhatsApp and contact flows
- Technical SEO fundamentals
- AI-assisted development and QA
- Production deployment with Vercel

## Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- Framer Motion
- next-seo
- Vercel

## Local development

~~~bash
npm install
npm run dev

npm run lint
npm run build
~~~
